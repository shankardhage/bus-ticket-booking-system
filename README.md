# 🚌 SD Travels - Bus Ticket Booking System

A modern online bus ticket booking system built using PHP, MySQL, Bootstrap, JavaScript, and AJAX.

This project allows users to search buses, select seats, lock seats temporarily, enter passenger details, and confirm bookings with a smooth UI similar to real-world ticket booking platforms.

---

# 🚀 Features

## 👤 User System
- User Registration
- User Login & Logout
- Session Management

## 🚌 Bus Booking
- Search buses by source & destination
- View available buses
- Real-time seat availability
- Sleeper seat layout (Upper & Lower deck)
- Multiple seat selection
- Seat lock system with timer
- Passenger details form
- Booking confirmation

## 🎟️ My Bookings
- View booked tickets
- Booking history
- Ticket status

## 🎨 UI Features
- Modern Bootstrap UI
- Responsive design
- Image slider/banner
- Premium navbar & footer
- Offer section
- Why Choose Us section
- Animated feature cards
